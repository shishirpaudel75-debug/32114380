# NorthStar Urban Mobility Analytics
## Databases and Analytics — University of West London

This repository contains all analytical notebooks for the NorthStar Urban Mobility and Logistics case study assignment.

## Notebooks

| Notebook | Language | Content |
|---|---|---|
| `01_sql_in_r.ipynb` | R | 5 SQL queries via sqldf |
| `02_r_analytics.ipynb` | R | Statistical tests + 5 ggplot2 visualisations |
| `03_python_analysis.ipynb` | Python | pandas/NumPy/seaborn analysis + charts |
| `04_mongodb_atlas.ipynb` | Python | MongoDB Atlas: 3 collections, CRUD, indexes, aggregation |

## Key Findings
- Business orders fail at 19.88% — highest failure rate despite highest margin
- Central zone failure rate 20.11% — worst performing zone
- 18.8% of OnTime records actually exceeded their promised delivery window
- App chat escalation fails 50% of the time
